# Clase 4 — Operadores y expresiones en Python (Teoría)

Diapositivas base del tema 4: continuación directa de la clase 3, retomando el ejemplo del área de un círculo para introducir expresiones y los tres grandes grupos de operadores de Python (aritméticos, relacionales y lógicos), y cómo se combinan mediante reglas de prioridad y asociatividad. 26 diapositivas. ## Contenido cubierto

- **Repaso del método de Polya** aplicado una vez más al ejemplo del área de un círculo, ya codificado en Python.
- **Entrada, procesamiento y salida**: modelo *Inputs → Process → Outputs* y su equivalente en bloques, pseudocódigo y Python.
- **Expresiones y operadores**: qué es una expresión (operandos + operadores → un resultado); clasificación en operadores de asignación, relacionales, aritméticos y lógicos.
- **Operadores aritméticos**: `+`, `-`, `*`, `/`, `//`, `%`, `**` (o `^`), con ejemplos numéricos de cada uno.
- **Reglas de prioridad y asociatividad**: tabla completa (paréntesis → potenciación → identidad/cambio de signo → multiplicación/división/módulo/división entera → suma/resta) con su asociatividad (izquierda-derecha o derecha-izquierda) y ejercicios de evaluación paso a paso.
- **Expresiones algebraicas vs. expresiones para computador**: cómo traducir una fórmula matemática a una línea de código válida.
- **Operadores relacionales**: `>`, `>=`, `<`, `<=`, `==`, `!=`, con tabla de ejemplos y resultado booleano.
- **Operadores lógicos**: `not`, `and`, `or` (con sus alias `~`, `&`, `|`), incluyendo las tablas de verdad completas.
- **Tabla resumen de prioridad** combinando ya todos los operadores vistos (aritméticos, relacionales y lógicos) en un solo orden de evaluación.
- **Ejercicios de repaso**: traducir expresiones algebraicas a expresiones algorítmicas, identificar identificadores válidos, y evaluar expresiones dados valores concretos de variables.
