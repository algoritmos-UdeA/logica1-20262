# Clase 2 — Algoritmos y diagramas de flujo (método de Polya)

Este tema introduce el método de Polya para plantear y resolver problemas de forma algorítmica: cómo representar sus pasos con datos (variables y constantes), con diagramas de flujo y con pseudocódigo, y cómo traducir ese planteamiento a los primeros programas en Python. Se desarrollan tres ejemplos guiados de principio a fin (área de un triángulo, meses entre dos años, nómina) y se cubre en cuatro sesiones magistrales, dictadas primero de forma presencial y luego virtual.
