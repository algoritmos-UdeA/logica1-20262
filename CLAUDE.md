- **Course conventions for arreglos/listas** (pedagogical decisions taken with the instructor in Cowork, 2026-10-18 — apply them to clase 11 and everything after it: clase 12, matrices, archivos, labs, talleres):
  - Array pseudocode has **no types**: `notas = Arreglo(N)`, and literals written like Python, `[3.0, 4.5, 2.0, 4.0]`. Functions are shown **only in Python** — there is no function syntax in the course pseudocode.
  - The arreglo and the Python list are presented **together from the definition on**, as "la lista usada como arreglo" under explicit rules: fixed size created with `[0.0] * N`, a single data type, access by position `0..N-1`. Every basic operation is shown in two columns, pseudocódigo | Python.
  - Basic operations use `N` and `range(N)`; `len()` is introduced when lists are passed to functions (where the function doesn't receive `N`).
  - Python's negative indices are allowed at the student's discretion (e.g. `notas[-1]` for the last element). The warning that is taught: a negative index does **not** raise an error and can hide bugs (`notas[i - 1]` with `i = 0` silently takes the last element), whereas an index that is too large does raise `IndexError`.
  - Full traversals go from 0 to N - 1 (`range(N)`).
  - In pseudocode (and in C) negative indices don't exist: the last element is `notas[N - 1]`.
  - **No `append`/`remove` or any other list method** — they're deferred to POO, with the explanation "en Python todos los datos son objetos; `objeto.operación()` se explica en POO". Clase 12 and matrices also work without `append` (a matrix is built as `matriz = [0] * N` and then `matriz[i] = [0.0] * M` per row). How to read files without `append` is **still undecided** — ask the instructor before choosing.
  - A function that modifies the list it receives is valid **if its Garantiza says so** (otherwise Garantiza should state "No modifica …").
  - No NumPy, no type hints; `math` is allowed from clase 10 on.
