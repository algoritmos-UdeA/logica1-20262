## Repository state

This is a course repository for "Lógica y Representación I" (UdeA, 2026-2). It has no build tooling or test suite — it's course planning documents, reference material, and small standalone example scripts:

- `README.md` — full course overview (in Spanish): general info, purpose, learning outcomes, thematic units, summarized schedule, evaluation weights, methodology (flipped classroom + project-based learning), reference bibliography, complementary online courses/judges/gamified platforms, and communication channels
- `2508208_LÓGICA Y REPRESENTACIÓN I.pdf` — official course microcurriculum/syllabus
- `planeacion_tentativa/cronograma.md` — tentative semester schedule (superseded the old `planeacion/cronograma.md`, now removed): session-by-session topics (continuous class numbering 1–48 across 16 weeks), the fixed weekly time slots (Monday lab, mid-week 4h theory block), evaluation weights/dates, and notes on how the unit order and weekly slot order deviate from the official microcurriculum
- `clases/README.md` — index/table of contents of per-class materials plus a session-by-session log ("Bitácora de sesiones"); kept up to date as of 2026-08-14, covers clases 0-4 and links into each `sesion_magistral-N/` folder — still worth cross-checking against `clases/` directly since it's manually maintained
- Per-class folder convention (introduced 2026-08-14, applied to clases 0-2 so far, not yet to clase 3): each `clases/<n>/` splits its material into `teoria/` (slides for the whole topic) and, when covering that topic takes more than one lecture, a `sesion_magistral-N/` folder per lecture (each with its own `README.md` stating **Tipo** and **Fecha**). `N` is a *continuous* counter across the whole course, not reset per clase — e.g. clase 2's sessions are numbered 3, 4, 5. Folder naming is inconsistent between hyphen/underscore (`sesion-magistral_1`, `sesion_magistral-2`, `sesion_magistral_3`, `sesion_magistral-4`) — don't assume a single pattern, check the actual folder name.
- `clases/0/` — Clase 0 "Presentación del curso": `README.md` with instructor info, course logistics, and links to Google Classroom/repo, `clase_00.pdf`/`.pptx` (slides), `diagrama_clase0.drawio` (source diagram), and `sesion-magistral_1/README.md` (session 1, 03/08/2026, presencial)
- `clases/1/` — Clase 1 "Conociendo las Herramientas de Trabajo": `README.md` covering required/optional tool installs (Anaconda, VS Code, draw.io, PyCharm), online practice tools (Python Tutor, CodeSkulptor), gamified warm-up activities (Code.org), and a student checklist; slides now under `teoria/clase-01.pdf`/`.pptx`; `sesion_magistral-2/README.md` (session 2, 04/08/2026, presencial)
- `clases/2/` — Clase 2, método de Polya / lógica de resolución de problemas: slides under `teoria/clase-02.pdf`/`.pptx`, `images/` (shared figures), `template_polya/` (plantilla en blanco del método Polya + `README.md`), and three session folders: `sesion_magistral_3/` (session 3, 04/08/2026, presencial, just started the topic), `sesion_magistral-4/` (session 4, virtual — moved presencial→virtual on short notice; formerly `apuntes_zoom/`; annotated PDF, `ejemplo_meses.py`/`ejemplo3_areacirculo.py`, `resumen.md`), `sesion_magistral-5/` (session 5, virtual; formerly `apuntes_zoom_2/`; nómina example — `metodo_polya_nomina_UdeA.xopp`, `diagrama.drawio`/`.png`, `ejemplo_clase/`) — no top-level `clases/2/README.md` yet

- `clases/<n>/README.md` and `sesion_magistral-N/README.md` files are marked as drafted with generative AI from instructor prompts and reviewed by the instructor
- `material/cheat-sheets/` — quick-reference PDFs for Python and Java-vs-Python comparisons (e.g. `beginners_python_cheat_sheet_pcc_all.pdf`, `mementopython3-english.pdf`, `Java4Python.pdf`, `java_vs_python.pdf`, the Coding Club Python series, `CC-CodeCards.pdf`)

There is nothing to build, lint, or test at this stage. When more code is added to this repository, update this file with the actual commands and architecture rather than assuming a structure in advance.
